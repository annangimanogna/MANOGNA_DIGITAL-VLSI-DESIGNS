# MANOGNA_DIGITAL_VLSI_DESIGNS

This repository showcases my journey in Digital Design and VLSI Frontend using Verilog HDL. It contains implementations ranging from basic logic circuits to advanced RTL designs, with an emphasis on understanding digital hardware design step by step.

## Contents

* Verilog Basics
* Combinational Circuits
* Sequential Circuits
* FSM Design
* Memory Modules
* Communication Interfaces
* RTL Design Projects
* Verification

## Tools

* Xilinx Vivado
* EDA Playground

## Objective

To build a well-organized collection of Verilog HDL projects for learning, practice, and interview preparation in VLSI frontend and FPGA design.
