# Dataflow level 
## The module implementation depends on data flow specification i.e. how data flows and processes in the design circuit.
-------------------------------------
### 1)The main keyword used in  data flow is "assign".
### 2)Continous Assignment
### syntax: assign LHS=RHS;
### 3)RHS can be an expression or a variable.
### 4)If RHS value changes then it calculates RHS value and assign to LHS
### 5)LHS should be data type 
### 6)Size of LHS should accumulate RHS value.
